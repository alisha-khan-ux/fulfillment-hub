# Fulfillment Hub

A Streamlit prototype for XYZ e-commerce fulfillment operations.

## Problem

XYZ manages around 200–300 orders per day using spreadsheets and shared folders. This makes it difficult to track order status, identify priority orders, monitor stock availability, coordinate courier pickups, and follow up on operational issues.

## Solution

Fulfillment Hub provides a centralized control center for warehouse and fulfillment teams.

## Features

- Dashboard with key fulfillment metrics
- Priority order monitoring
- Order search and filtering
- Inventory visibility across main and secondary warehouses
- Stock transfer suggestions
- Shipping and staging monitoring
- Courier pickup visibility
- Centralized issue tracking

## Technology

- Python
- Streamlit
- Pandas

## Run Locally

Install the required packages:

```bash
python3 -m pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

The application uses dummy/sample data for demonstration purposes.
